# Shatter

Shatter is a browser based gravity well rock shooter. Fly on momentum, bend shots around the central star, break armored rocks through their fragments, and save the homing torpedo for a hard target.

## Run it

```sh
npm ci
npm run dev
```

Build the static site with `npm run build`; the complete site is written to `dist/`. Serve that directory from any static file server.

## Controls

- **Arrow keys / WASD:** turn and thrust
- **Space:** fire the gun
- **F:** launch the recharging torpedo
- **Enter / Space:** confirm a menu choice
- **Escape / P:** back or pause
- **M:** mute audio

The on-screen touch controls are available on touch devices. The title menu includes a how-to screen.
